<h1>Shopping Cart</h1>

A responsive React e-commerce web application fetching product data from an API.<br>
This project is based on <a href="https://www.theodinproject.com/" target="_blank" rel="noreferrer">The Odin Project</a>.

<h3>Features</h3>

- Dynamic product data fetching from DummyJSON.

- Real-time item count calculations, interactive quantity adjustments, and removal logic.

- Page navigation with React Router (Home, Shop, Cart, ErrorView).

- Responsive Design implemented with CSS Modules.

- Test suite for component logic and mock API hooks with Vitest and React Testing Library.

<h3>Tech Stack</h3>

- Frontend: React 19, JavaScript, CSS Modules

- Build Tool: Vite

- Routing: React Router v8

- Testing: Vitest, React Testing Library, @testing-library/user-event
