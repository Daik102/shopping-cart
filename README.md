<h1>Project: Shopping Cart</h1>

A responsive React e-commerce web app with several features<br>
This project is based on <a href="https://www.theodinproject.com/">The Odin Project</a>.

<h3>Features</h3>

- Dynamic product data fetching from <a href="https://dummyjson.com/">DummyJSON</a>

- Real-time item count calculations, interactive quantity adjustments, and removal logic

- Page navigation with React Router (Home, Shop, Cart, ErrorView)

- Responsive Design implemented with CSS Modules

- Test suite with Vitest and React Testing Library

<h3>Tech Stack</h3>

- Frontend: React, CSS Modules, JavaScript

- Build Tool: Vite

- Routing: React Router

- Testing: Vitest, React Testing Library, @testing-library/user-event
