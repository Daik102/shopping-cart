<h1>Odin Shopping Cart</h1>

A responsive React e-commerce web application featuring API-driven product listings, live cart updates, client-side routing, and a comprehensive automated test suite.

<h3>Features</h3>

- Product Showcase: Dynamically fetches product data from FakeStoreAPI.

- Shopping Cart Management: Real-time item count calculations, interactive quantity adjustments, and removal logic.

- Client-Side Routing: Page navigation using React Router (Home, Shop, Cart, ErrorView).

- Mobile-Responsive Design: Tailored layouts using CSS Modules.

- Unit & Integration Testing: Fully tested component logic and mock API hooks using Vitest and React Testing Library.

<h3>Tech Stack</h3>

- Frontend: React 19, JavaScript (ES6+), CSS Modules

- Build Tool: Vite

- Routing: React Router v8

- Testing: Vitest, React Testing Library, @testing-library/user-event
